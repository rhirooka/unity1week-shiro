# Snow Escape - 雪原鬼ごっこ 設計まとめ

このドキュメントは、Web版デモ（`index.html`）を作る過程で固めた設計をまとめたものです。
Unity版を実装する際の参考資料として使います。

> **注記**：リポジトリのREADMEには「一定時間生き残ると雪原がリセットされ、Waveが始まる」という記述がありますが、
> これは古い内容です。現状の最新仕様は本ドキュメント通り（**Waveなし・雪原はリセットしない・残機制のタイムアタック**）です。
> READMEは追って更新予定です。

## コンセプト

* 雪の積もった広場を舞台にした鬼ごっこ形式のタイムアタックゲーム
* 敵の姿は見えず、足跡だけが手がかり
* 見た目は3D、見下ろし視点（画面全体に固定カメラで収まる、スクロールなし）

## 勝敗・スコア

* プレイヤーは最終的に鬼に捕まる前提。生存時間そのものがスコア
* 残機3、被弾時2秒の無敵時間
* 残機が尽きたらゲーム終了、その時点の生存時間を記録
* 生存時間が1分、2分、3分……に到達するたび、経過時間を画面中央に一時的に表示する

## 敵AI

* 複数体。プレイヤーの座標を直接追うシーク型（視野角判定はしない。マップが完全にオープンなため単純化した）
* 目標座標は0.5秒おきに再取得する（毎フレーム完全追尾だと不自然に強く感じるため）
* 個体ごとに移動速度・反応タイミングに若干のばらつきを持たせる
* 初期4体（広場の四隅からスタート）、以後10秒ごとに1体をランダムな角に追加。上限なし
* 追加される敵（初期4体は対象外）のうち1/3の確率で「足跡が3倍サイズ」の個体が出現する
* 敵ごとに動き方を変え、プレイヤーを追わずにその場から動かない敵が出現する場合もある
* 敵の中には、ときどき一時的に速度を上げてプレイヤーに向かって走ってくる個体もいる

## 足跡・雪システム（コアメカニクス）

* 雪原はグリッドで管理。各マスは「未踏」か「踏み固め済み（永続）」の2状態のみ
* 一度でも踏まれたマスは、その場で即座に・永久に変化する（雪は元に戻らない。何度踏まれても状態は変わらない）
* 踏まれた瞬間、進行方向に沿って人の足跡（左右交互・楕円形）を実際の座標に焼き込む
* 足跡は不透明の固定色。重なって描かれても色が濃くなることはない
* 鬼は移動時に常に足跡を残す。プレイヤーも通常歩行時から足跡を残し、ダッシュ中は通常より大きな足跡を残す
* プレイヤー自身の足跡は、鬼の索敵には一切影響しない（非対称設計。対称型にする案もあったが、まずはシンプルな非対称型を採用）

## マップ

* 完全にオープンな広場、内部に遮蔽物は無し
* 外周に装飾の木を配置（当たり判定・視界には無関係、見た目だけ）
* 固定の正投影カメラで、広場全体が常に画面に収まる（スクロール・追従なし）
* カメラは真上から少し傾ける（約22度）ことで、奥行きが感じられるようにする
* ライティング（環境光＋斜めからの平行光）と影を使って立体感を出す

## プレイヤー

* 移動：WASD / 矢印キー
* ダッシュ：Shift（スタミナを消費。切れたら自動解除。ダッシュしていない間はスタミナが回復する）
* 見た目は仮のアバター（円柱の胴体＋球の頭）。本番では専用のアバターに差し替える予定

## 画面構成

* **タイトル画面**：タイトルは「Snow Escape」。ゲーム背景が透けて見えない、独立した画面。「スタート」ボタンで開始
* **ゲーム画面**：タイマー・残機・スタミナバーを表示。1分、2分、3分……に到達するたび、経過時間を画面中央に一時的に表示する
* **終了画面**：生存時間を表示。「もう一度」（即座に再プレイ）と「タイトルへ戻る」の2ボタン
* 敵に接触した際は、被弾したことが分かるようにヒット音と視覚的なエフェクトを表示する

## Web版デモの技術構成（参考実装）

* three.js（r128、CDN経由の単一HTMLファイル）
* 「ロジック層」（雪グリッド・敵AI・スコアなどのゲームルール）と「描画/UI層」を分離して実装している
* この分離のおかげで、ロジック部分はUnity移植時にC#クラスとしてほぼそのまま再実装できる

## Unity移植時の対応関係（目安）

| Web版（three.js）               | Unity版（想定）                                          |
| ---------------------------- | --------------------------------------------------- |
| 雪グリッド（2次元配列）                 | 2次元配列 or `Texture2D`                                |
| 各敵オブジェクト（配列で管理）              | `MonoBehaviour`コンポーネント、またはECS的な管理                   |
| ゲーム状態（生存時間・残機・敵追加タイマー等）      | `GameManager`的なシングルトンクラス                            |
| Canvasへの足跡描画                 | `Texture2D`へのピクセル書き込み、または個別のDecal/Quadインスタンス        |
| `OrthographicCamera` + 傾き22度 | UnityのCameraコンポーネント（Projection: Orthographic）を同様に配置 |
| タイトル/ゲーム/終了の画面切り替え           | UnityのSceneまたはCanvas切り替え                            |
